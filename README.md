# Datheon AI Internship Projects

A collection of hands-on projects developed during the **Python + Generative AI & LangChain Internship at Datheon**.

## Internship Overview

- **Organization:** Datheon
- **Domain:** Python, Generative AI & LangChain
- **Focus:** Building practical AI applications using LLMs, Retrieval-Augmented Generation (RAG), AI agents, and Streamlit.

## Projects

### Task 02 – Document Q&A Assistant with RAG

**Objective:** Build an AI assistant that answers questions using information from uploaded documents.

**Planned features:**
- PDF and text document loading
- Text chunking
- Vector embeddings
- ChromaDB vector storage
- Retrieval-Augmented Generation (RAG)
- Source-based answers

### Task 03 – Multi-Tool Autonomous AI Agent

**Objective:** Develop an AI agent capable of selecting and using tools to perform tasks.

**Planned features:**
- LangChain agent
- Search tool
- Python calculator
- Local file reader
- Tool execution and result handling

### Task 04 – Interactive AI Chatbot with Streamlit

**Objective:** Create an interactive AI chatbot with a user-friendly interface.

**Planned features:**
- Streamlit chat interface
- Conversation history
- Session state
- Integration with an AI pipeline
- Interactive responses

## Installation

1. Clone this repository:

```bash
git clone https://github.com/Shazmeen45/Datheon-AI-Internship.git
```

2. Navigate to the project directory:

```bash
cd Datheon-AI-Internship
```

3. Create and activate a virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

4. Install dependencies:

```bash
python -m pip install -r requirements.txt
```
